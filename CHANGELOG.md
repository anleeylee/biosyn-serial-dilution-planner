# Changelog

## [1.0.0] - 2024-01-01
### Added
- Mode B: fixed dilution factor serial dilution (1:10, 1:100, etc.)
- Mode C: user-defined target concentrations
- Mode A: concentration series
- Tube-by-tube operation plan (source, transfer, diluent, final volume, concentration)
- Safety checks: small transfer volume, large dilution factor, insufficient stock
- Auto tube label generation (S01-T01 format)
- Reverse calculation (target → stock volume + diluent)
- XLSX export (Summary, Dilution Plan, Tube Labels, Warnings, Methods)
- CSV export
- Offline / local-first operation
